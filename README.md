# 💗 Nébula

Uma **pet virtual de bolso** feita em HTML, CSS e JavaScript puro por alunos do **8º ano** na aula de Robótica.

A Nébula reage a toque, inclinação do celular, chacoalhadas, tem personalidade própria, fica doente, sente fome, dança, brinca e explora uma cidade.

> 🎓 Projeto escolar — primeiro trabalho do grupo na disciplina de Robótica.

---

## ✨ O que ela já faz

- 😊 **Expressões** — feliz, triste, brava, tonta, com sono, apaixonada, doente...
- 🧠 **6 personalidades** — carinhosa, curiosa, tranquila, brincalhona, temperamental e reservada. Cada uma reage diferente!
- 📱 **Sensores do celular** — reage à inclinação, chacoalhadas, quedas, caminhada e até à bateria baixa
- 🍎 **Sistema de comida** — com preferências (gosta de uma fruta, odeia outra)
- 🤒 **Doença e xarope** — fica gripada de vez em quando
- 🎮 **Minigames** — Cesta de Frutas, Borboletas, Banho e Dança
- 🌳 **Nébula City** — praça, jardim e eventos (em expansão)
- 💾 **Salvamento automático** — tudo fica guardado no navegador

---

## 🚀 Como rodar

### No celular (recomendado)
1. Abra o link do projeto publicado (GitHub Pages)
2. Aceite as permissões de sensores quando pedir
3. Toque, incline e interaja!

### No computador (para testar)
1. Baixe os 3 arquivos (`index.html`, `style.css`, `game.js`)
2. Dê **duplo-clique** no `index.html`
3. Ele abre no navegador e funciona — sensores ficam desativados, mas o resto roda

---

## 📁 Estrutura

```
nebula/
├── index.html     — o esqueleto da página
├── style.css      — toda a aparência (olhos, boca, animações)
├── game.js        — toda a lógica do jogo
└── README.md      — este arquivo
```

Dentro do `game.js`, o código está dividido em **13 seções comentadas**:

1. Utilidades
2. Estado (S) + save/load
3. Personalidade
4. Rosto / expressões
5. Sensores
6. Toque
7. Tédio automático
8. Comida
9. Doença / xarope
10. Minigames
11. Mundo
12. UI
13. Loop principal

Cada pessoa do grupo pode ficar responsável por uma ou duas seções.

---

## 🛠️ Tecnologias

- **HTML5** + **CSS3** (expressões feitas só com CSS!)
- **JavaScript puro** (sem frameworks)
- **Canvas API** para os minigames
- **DeviceMotion / DeviceOrientation** para sensores
- **localStorage** para salvar o progresso
